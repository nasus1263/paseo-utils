Small conveniences for Paseo.

Press Ctrl+Shift+C while a workspace is open to launch Windows Terminal in that workspace's directory (the worktree directory for worktree workspaces, otherwise the project root). The terminal opens on the daemon machine. The shortcut works in the desktop and browser apps, not on mobile, and is ignored while focus is inside a Paseo terminal so its copy shortcut keeps working.

Requires a Windows daemon with Windows Terminal (`wt.exe`) installed.
